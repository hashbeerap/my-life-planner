# My Life Planner - AI Assistant 🌙

## بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ

A free Islamic life planner to help Muslims organize their spiritual journey across all 12 Hijri months.

## Features ✨

### 📿 Salawat Counter
- Track daily, weekly, monthly, and lifetime salawat
- Set custom daily goals
- Quick add buttons (+1, +10, +100, +1000)
- Visual progress tracking

### 📖 Quran Tracker
- Set completion goals (1-3 Khatm or by pages)
- Track your progress
- Visual progress bar
- Reset and start fresh anytime

### 🕌 Prayer Tracker
- Log all 5 daily prayers
- Track prayer streaks
- Weekly statistics
- Easy checkbox interface

### 📅 Islamic Calendar
- Detailed action plans for all 12 Islamic months
- Special focus on Ramadan, Sha'ban, and Dhul Hijjah
- Recommended fasting days
- Important Islamic dates

### 💾 Backup & Restore
- Export your data as JSON file
- Import to restore on any device
- Never lose your spiritual progress
- Privacy-focused (all data stored locally)

### 🌍 Multi-Language Support
- **English** - Full support
- **Arabic (العربية)** - Full RTL support
- **Malayalam (മലയാളം)** - Full support

## How to Use 📱

1. **Open the planner** in any web browser
2. **Select your language** (top right corner)
3. **Navigate** using the menu buttons
4. **Track your ibadah:**
   - Click on Salawat to count your blessings on the Prophet ﷺ
   - Click on Quran to track your reading progress
   - Click on Prayer to log your daily prayers
   - Click on Calendar to see monthly Islamic action plans
5. **Backup regularly** in Settings to save your progress

## Monthly Plans 📆

The planner includes detailed action plans for:
- **Muharram** - New year goals, Ashura fasting
- **Safar** - Building consistency
- **Rabi al-Awwal** - Focus on Seerah
- **Rajab** - Spiritual preparation
- **Sha'ban** - Salawat focus, Ramadan prep
- **Ramadan** - Fasting, Quran, Laylatul Qadr
- **Dhul Hijjah** - First 10 days, Hajj, Eid

## Technical Details 🔧

- **Pure HTML/CSS/JavaScript** - No frameworks needed
- **LocalStorage** - All data saved in your browser
- **No server required** - Works offline after first load
- **Mobile-friendly** - Responsive design
- **Privacy-first** - Your data never leaves your device

## Installation 💻

### Option 1: Direct Use
Simply open `index.html` in any web browser!

### Option 2: Local Server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

Then visit `http://localhost:8000`

### Option 3: Online Hosting
Upload all files to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service

## Data Privacy 🔒

- All data stored **locally** in your browser
- No accounts or registration required
- No data sent to any server
- No tracking or analytics
- 100% private and secure

## Backup Instructions 💾

1. Go to **Settings** page
2. Click **"Export Backup"**
3. Save the JSON file somewhere safe
4. To restore: Click **"Import Backup"** and select your file

**Tip:** Backup weekly to keep your progress safe!
